# 左右分屏

## 行为

- 右上角分屏图标切换进入/退出；画布工作区等分左右，左侧保留主笔记编辑。
- 右侧初始显示“轻触选择副笔记”，点击打开现有资料库树选择器；标题按钮可更换副笔记。
- 副笔记可读写，与主笔记共享底部工具栏模式、笔型、颜色、笔宽、文字尺寸和框选样式；支持拖动、书写、擦除、插入与框选。两侧各自持有文档、撤销栈和 PDF 页码。
- 工具栏顺序为“合并页 → 分屏 → 草稿纸”；合并页用汇聚页图标，分屏用左右双框图标。中线为 2dp 可见分界线。
- 撤销/重做操作最近触碰的一侧；右侧可插入文本、图片、书签、链接、强调和传送点，可框选移动/删除/复制/剪切/缩放/折叠，副笔记的框选菜单不包含主侧 AI 提问、识别、错题本、草稿计算等扩展入口。
- 副笔记完成手势、翻页、更换、退出分屏和后台时保存；保存失败显示错误并阻止退出或更换。跨界取消同步恢复笔迹、视图、附加对象及撤销状态；插入等到有效抬手才触发。
- 副笔记候选排除主笔记 ID；切换主笔记使两侧 ID 一致时立即清空副笔记，即使 PDF 页码不同也清空。
- 手势归属在按下时确定；任意触点或历史采样跨过中线，使整次触摸流失效，发送取消并恢复操作前视图。手指回到原侧不会恢复，需抬手重新操作。
- 退出分屏清空副笔记，下次进入重新选择；没有新增笔记文件格式或资料库迁移。

## 实现定位

- `ui/SplitWorkspaceLayout.kt`：关闭 Android 分指分发、整次触摸归属和取消。
- `ui/SplitGestureGuard.kt`：不依赖 Android 的边界判断、笔记身份规则。
- `ui/SplitNoteController.kt` 与 `ui/SecondaryNoteEditor.kt`：副笔记加载、保存、编辑、过期结果丢弃、独立 PDF 翻页。
- `canvas/CanvasGlView.kt`：分屏取消恢复视图，取消事件不再触发拖动模式点击。
- `ui/MainActivity.kt` 与 `res/layout/activity_main.xml`：入口和工作区集成、主 PDF 下一页按钮定位、生命周期。

真机验收：
1. 进入/退出后左右等分、主笔记位置保持；副笔记选择标题不被工具栏挡住。
2. 左右分别拖动/缩放，对侧不动；双指分处两侧、拖动穿过中线、穿过后返回均取消；全部抬手后新手势正常。
3. 右侧 PDF 独立翻页不更改左侧页码；更换不同页数 PDF 后页码正确。
4. 从侧栏/快捷栏/草稿纸/链接等入口把主笔记改为副笔记时，右侧回到占位提示。
5. 选择器打开时主笔记变化、快速切换副笔记、后台恢复和旋转；过期异步结果不覆盖新选择。
6. 左侧写入、撤销/重做、隐藏/恢复界面、导出、传送返回及侧栏动画回归。跨界对象拖动/选择编辑尚需实机重点验收。

读写专项验收：两侧分别书写与擦除，跨界后笔迹/对象/撤销栈回到手势前；文本/图片插入跨界不弹窗；切换副笔记、翻 PDF、退出/后台后重开内容保留；主副 ID 冲突时先保存副笔记再清空；确认两个独立撤销栈不串页。设备测试中的工具配置改动会影响测试设备笔刷偏好，应在独立测试安装/模拟器运行。
